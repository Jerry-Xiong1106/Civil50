## 预期交互

当事人开场　接手房子后没能续租，我想把转让费要回来，先看哪个约定？

期望成果　准备一份调解陈述、材料清单及结果核对表。

**追问 1**　关于转让费，当时的情况或记录是怎样的？

模拟答复　原告请求退回已支付的10万元转让费。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [28, 35)。

**追问 2**　关于续租条件，当时的情况或记录是怎样的？

模拟答复　约定未能续约下一年租期时退还转让费。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [139, 148)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　channel → participate → result。首次交付后要求明确区分证实与待核项，重新交付后确认。
