## 预期交互

当事人开场　商铺欠租，我既要收回房子又想要赔偿，要分别准备什么？

期望成果　列出能确认的事实、尚缺的依据和下一步。

**追问 1**　关于已付租金，当时的情况或记录是怎样的？

模拟答复　被告已付租赁费8000元。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [81, 89)。

**追问 2**　关于赔偿约定，当时的情况或记录是怎样的？

模拟答复　租赁合同未约定违约责任，法院说理记载尚无实际损失发生。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [173, 181)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　answer。收到完整交付后确认。
