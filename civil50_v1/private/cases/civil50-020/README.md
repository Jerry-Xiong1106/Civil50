# civil50-020 · 借条是一个人写的，我能把另一个人也列进去要钱吗？

## 预期交互

当事人开场　借条是一个人写的，我能把另一个人也列进去要钱吗？

期望成果　整理管辖待核事项、证据目录、起诉状草稿和提交清单。

**追问 1**　关于借据，当时的情况或记录是怎样的？

模拟答复　原告提交了借条，主张本金20000元。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [31, 37)。

**追问 2**　关于共同债务，当时的情况或记录是怎样的？

模拟答复　原案中证明两名被告系夫妻的证据不足。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [114, 118)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　jurisdiction → evidence → draft → submit。首次交付后要求明确区分证实与待核项，重新交付后确认。

## 评审依据

个人借据不能单独证明另一人共同负债。
