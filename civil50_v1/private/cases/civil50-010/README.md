# civil50-010 · 我开车时发生事故，想由我去做车损鉴定、找对方赔钱，需要谁授权？

## 预期交互

当事人开场　我开车时发生事故，想由我去做车损鉴定、找对方赔钱，需要谁授权？

期望成果　整理管辖待核事项、证据目录、起诉状草稿和提交清单。

**追问 1**　关于事故责任，当时的情况或记录是怎样的？

模拟答复　事故认定另一方全责，本车驾驶人无责。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [208, 212)。

**追问 2**　关于代理授权，当时的情况或记录是怎样的？

模拟答复　索赔的驾驶人不是受损车主，也没有受委托起诉。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [106, 113)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　jurisdiction → evidence → draft → submit。首次交付后要求明确区分证实与待核项，重新交付后确认。
