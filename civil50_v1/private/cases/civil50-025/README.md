# civil50-025 · 同一个人分两次借钱、写了两张借条，我该怎么列？

## 预期交互

当事人开场　同一个人分两次借钱、写了两张借条，我该怎么列？

期望成果　列出能确认的事实、尚缺的依据和下一步。

**追问 1**　关于第一笔借款，当时的情况或记录是怎样的？

模拟答复　第一笔30000元，原告称对方承诺三个月还。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [85, 92)。

**追问 2**　关于第二笔借款，当时的情况或记录是怎样的？

模拟答复　第二笔20000元，对方承诺5月28日还款。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [117, 126)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　answer。收到完整交付后确认。
