# civil50-002 · 碰车以后对方答应付修车钱，我还可以向他要多少？

交通事故 · 协商 · 开发 · 就指定核账问题材料充分

## 预期交互

当事人开场　碰车以后对方答应付修车钱，我还可以向他要多少？

期望成果　整理一份双方可以核对的协商方案和履行清单。

**追问 1**　关于赔付约定，当时的情况或记录是怎样的？

模拟答复　双方谈定赔付4000元。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [141, 145)。

**追问 2**　关于已经支付，当时的情况或记录是怎样的？

模拟答复　原告称保险公司付了2000元，剩余部分由对方写了欠款。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [162, 167)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　prepare → communicate → perform。首次交付后要求明确区分证实与待核项，重新交付后确认。

## 评审依据

区分协议总额、已付和待付。

案件受理费50元，由被告单晓龙负担。
