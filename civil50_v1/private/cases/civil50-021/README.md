模拟答复　原告就100万元借款主张对抵押房产行使抵押权。

**追问 2**　关于律师费用，当时的情况或记录是怎样的？

模拟答复　原告承认签抵押合同时双方没有谈到律师费。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [241, 248)。
