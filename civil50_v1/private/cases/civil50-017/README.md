## 预期交互

当事人开场　借钱时留了借条，也有我取钱的凭证，这两样能说明什么？

期望成果　列出能确认的事实、尚缺的依据和下一步。

**追问 1**　关于交付证据，当时的情况或记录是怎样的？

模拟答复　原案提到借条和取款凭证。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeReason` 的字符 [54, 58)。

**追问 2**　关于到期利息，当时的情况或记录是怎样的？

模拟答复　原告所述本金30000元，到期日为2015年12月30日。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [52, 63)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　answer。收到完整交付后确认。
