# civil50-029 · 赊出去的建材款，对方签过还款计划，也还过钱，怎么对账？

买卖合同 · 诉讼准备 · 开发 · 部分法律覆盖

## 预期交互

当事人开场　赊出去的建材款，对方签过还款计划，也还过钱，怎么对账？

期望成果　整理管辖待核事项、证据目录、起诉状草稿和提交清单。

**追问 1**　关于欠据金额，当时的情况或记录是怎样的？

模拟答复　原告称追索后尚欠45000元。

按请求上传 [摘记 1](materials/note-1.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [183, 191)。

**追问 2**　关于后续还款，当时的情况或记录是怎样的？

模拟答复　原告称对方2017年6月28日依计划又还了10000元。

按请求上传 [摘记 2](materials/note-2.txt)，核对第 3 行。评审定位为 `JudgeAccusation` 的字符 [279, 289)。

泛问或超出材料范围时答「我目前只能提供已有摘记，其他情况还要核实。」。只在问到相应事项时披露该条。

路线步骤　jurisdiction → evidence → draft → submit。首次交付后要求明确区分证实与待核项，重新交付后确认。
