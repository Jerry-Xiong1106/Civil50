# 宋兴福诉单晓龙机动车交通事故责任纠纷

本包重构一次从事故核账到协商或起诉准备的咨询。金额口径为原案审理时。案件数据与原始记录置于评审侧。开场可以只说“碰车以后对方答应付修车钱，我还可以向他要多少？”

| 文件 | 用途 |
|---|---|
| [M1 事故及修车费用摘记](当事人材料/M1_事故及修车费用摘记.pdf) | 对方问到事故、责任或修车材料时提供 |
| [M2 赔付约定及收款摘记](当事人材料/M2_赔付约定及收款摘记.pdf) | 对方问到保险赔付、书面承诺或履行材料时提供 |
| [修车款催告函](文书/修车款催告函.pdf) | 起诉前的协商文书拟稿 |
| [民事起诉状](文书/民事起诉状.pdf) | 按上游记载的原诉请重构的草稿 |
| [民事判决记录](评审/民事判决_公开记录排印本.pdf) | 核对查明事实、说理和主文 |
| [案件询问与参考答复](评审/案件询问与参考答复.pdf) | 8 轮示例、材料披露条件和评分要点 |
| [案件数据](评审/案件数据.json) | 结构化事实、时间口径、来源指针及文件哈希 |
| [上游记录](来源/C3RD原始记录.json) | 与固定提交中完整记录逐字段比对 |

法院正式判决书 PDF、原告实际递交的诉状、事故认定书、维修票据和协议原件均未取得。两份摘记只用于测试上传；催告函、诉状和访谈均为重构，未签署或发送。上游诉称及查明部分对期限措辞略有不同，M2 保留两处表述。上游结构化 LegalBasis 与裁判说理列举的法条也有差异，判决阅读以逐字排印的说理和主文为准。

来源为 YeFD / MileCut 的 C3RD_mini（2.json，/ctxs/25）；发布者说明数据来源于公开裁判文书。仓库许可随包提供，第三方裁判文本的再发布条款未单列。本包为本地案例资料。 [固定版本](https://github.com/YeFD/MileCut/blob/e8e06dece41c2b5b2a84c0741861c3785935b68a/dataset/C3RD_mini/2.json)
